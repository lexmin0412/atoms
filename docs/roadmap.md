## 范围外（当前不考虑）

多 Agent 编排、多人协作、真实计费、工作流编排。

## 实现优先级（由核心向外收敛）

1. 先保核心闭环（M1–M3）与真实预览（M5）
2. 再加亮点（M4 / M6 / M7）
3. 最后做安全与全栈深化（M8–M10）

## 已知限制

- **预览隔离**：开发预览仍为同源 iframe；生产可改独立子域（发布已是独立子域）。
- **沙箱出网**：容器当前可访问外网（仅装包用），未做白名单。
- **发布应用**：常驻后端有硬上限（5）；未做按需唤醒/休眠、多副本、自定义域名。
- **计费**：未接真实计费，仅做每用户额度 + 上游配额兜底。
- **数据库查看**：只读（表/结构/分页），不支持自定义 SQL 或编辑。
